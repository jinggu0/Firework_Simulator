# V2-2f S-Map 2024 정사영상 촬영일·이용범위 문의서

이 문서는 서울시 S-Map 운영 담당에게 보낼 문의 초안과 회신 검증 체크리스트다.
저장소는 이 문의를 자동 제출하지 않으며, 신청자의 이름·연락처·소속 같은
개인정보를 기록하지 않는다.

요청 대상은 **자료 제공이 아니라 메타데이터**다. V2-2e에서 로컬 검증용으로
이미 확보한 `ortho_drone_25cm_2024` 타일에 대해 촬영일과 이용범위를 확인하는
것이 목적이며, 원시 타일의 공개 재배포는 요청하지 않는다.

## 확인된 제출 경로

- 게시판: S-Map Q&A `https://smap.seoul.go.kr/guide/qna.html` (비회원 글쓰기 가능)
- 담당: 서울특별시 공간정보과, 공표 연락처 `02-2133-2835`
- 근거: S-Map 공지사항 `448061`(2025-12-03)이 공간정보과와 위 번호를 S-Map 운영
  담당으로 명시한다. Q&A 목록에는 `담당부서` 열이 있고, 자료 관련 질문에
  관리자 `[Re]` 답변이 1~2일 내 게시된 이력이 확인된다.
- 브라우저 확인: 2026-08-04T05:04:12Z

## 문의 초안

```text
제목: S-Map 2024 정사영상(ortho_drone_25cm_2024) 촬영일 및 로컬 연구 이용범위 문의

2024년 10월 5일 당시 여의도한강공원 일대를 연구용 로컬 3D 시뮬레이션에서
검증하고 있습니다. 검증 과정에서 S-Map 배경지도 2024의 정사영상 레이어
ortho_drone_25cm_2024를 참조하였고, 대상 범위는 EPSG:5186 기준
E 194,044 ~ 194,428 / N 547,224 ~ 547,608 (약 384m x 384m, 서강대교 남단
여의도한강공원 일대), 해상도 0.25m/픽셀입니다.

다음 네 가지를 확인 부탁드립니다.

1. 위 범위를 덮는 ortho_drone_25cm_2024 정사영상의 정확한 촬영일 또는 촬영일
   범위는 언제입니까? 해당 범위가 단일 촬영분인지, 여러 날짜의 영상을 접합한
   모자이크인지도 함께 알려주시기 바랍니다.

2. 이 정사영상 레이어는 서울특별시가 저작권을 보유한 자료입니까, 외부기관
   제공 자료입니까? 외부기관 자료라면 기관명과 적용되는 저작권 정책을
   알려주시기 바랍니다.

3. 이 정사영상의 평면 위치정확도 성과(검사점 잔차, RMSE 등) 문서가 있습니까?
   있다면 공개 가능 여부와 열람 방법, 그리고 정사보정에 사용한 기준 표고면
   (DEM 또는 DSM)의 종류를 알려주시기 바랍니다.

4. 2025년 12월 3일 공지 "S-Map 지도 화면(캡처 이미지) 저작권 및 활용 안내"의
   자유이용 범위가, 지도 화면 캡처가 아니라 타일 서비스에서 직접 받은 타일
   이미지를 재배포 없이 로컬 연구 검증에만 사용하는 경우에도 적용됩니까?
   적용된다면 요구되는 출처 표시 문구를 확인 부탁드립니다.

원시 타일의 공개 재배포는 요청하지 않으며, 제공 조건을 준수해 로컬 검증에만
사용할 예정입니다. 확인이 어려운 항목이 있으면 담당 부서나 대체 확인 경로를
안내해 주셔도 좋습니다.
```

## 제출 전 확인

- 레이어명은 `ortho_drone_25cm_2024`, 좌표계는 `EPSG:5186`으로 명시한다.
- 행사일은 `2024-10-05`, 허용 촬영일 상한도 `2024-10-05`로 명시한다.
- 설정 소스 주석 `[202410]`과 `20241209`를 촬영일로 단정해 질문하지 않는다.
  이 값들은 기간 힌트와 배포 시점 힌트일 뿐이다.
- 게시판이 요구하는 이름·연락처·비밀번호는 저장소에 커밋하지 않는다.
- 비밀글로 올릴지 여부는 신청자가 판단한다. 회신을 증거로 인용하려면 제3자가
  확인할 수 있는 게시물 번호나 문서번호가 남아야 한다.

## 수령 시 보존할 증거

- 회신 게시물 번호 또는 공문 문서번호와 답변 부서
- 대상 범위를 덮는 촬영일 또는 촬영일 범위, 그리고 그 근거(구두 답변인지
  첨부 문서인지)
- 단일 촬영분인지 다중 날짜 모자이크인지
- 위치정확도 문서와 그 지표 명칭(RMSE, CE90 등)을 원문 그대로
- 타일 서비스 자료의 로컬 연구 이용 가능 여부와 요구되는 출처 표시 문구

회신은 `assets/smap_ortho_provider_reply.schema.json`에 맞춰 기록한 뒤 다음을
실행한다.

```powershell
python -m tools.audit_smap_ortho_provider_request --reply <회신파일경로>
python -m pytest tests/test_smap_ortho_provider_request.py -q
```

## 회신이 열지 못하는 것

촬영일 회신만으로는 행사일 표식 분류가 열리지 않는다. 감사는 세 조건을 모두
요구한다.

1. 대상 범위의 **가장 늦은** 촬영일이 2024-10-05 이하일 것 — 모자이크가 가장
   오래된 프레임으로 통과하는 것을 막는다.
2. 독립 검사점 잔차 1.0m 이하가 문서로 확인될 것.
3. 타일 자료의 로컬 연구 이용 범위가 확인될 것.

2번은 현재 보유 자료로 충족할 수 없다. 크롭 인근 국토지리정보원 공개
기준점 4개는 전부 `망실`이라 영상에서 식별할 수 없고 좌표상으로도 크롭
서쪽 390.4~702.0m로 범위 밖이다. 따라서 제공자 정확도 문서(질문 3)가 열리지
않으면 촬영일이 확인되어도 표식 분류는 계속 차단된다.

## 관측된 제공자 약관과 그 한계

S-Map 공지사항 `448061`(2025-12-03, 공간정보과)은 S-Map 지도 화면 캡처
이미지를 저작권법 제24조의2에 따라 별도 허락 없이 상업적·비상업적으로
이용할 수 있다고 안내하며, 출처 표시를 필수로 요구한다.

- 요구 출처 표기: `출처 : 서울시 S-Map(https://smap.seoul.go.kr)`
- 일부 레이어에는 외부기관 제공 자료가 포함될 수 있고, 그 경우 해당 기관의
  정책을 따라야 한다고 명시한다. 질문 2가 필요한 이유다.
- **범위 한계**: 이 공지는 "지도 화면 캡처 이미지"를 대상으로 한다. V2-2e가
  확보한 픽셀은 화면 캡처가 아니라 타일 서비스에서 직접 받은 타일이며,
  공지는 이 경우를 언급하지 않는다. 질문 4가 필요한 이유다.
- **표기 불일치**: 공지 본문은 상업적 이용을 허용하는데, 게시판은 그 게시물
  자체에 공공누리 제4유형(출처표시+상업적이용금지+변경금지)을 표시한다.
  스탬프는 게시물에, 본문은 지도 캡처에 적용되는 것으로 읽히지만, 저장소는
  이 차이를 추정으로 해소하지 않고 그대로 기록한다.

S-Map Q&A 공지 `441460`(2025-08-18)은 서울시 3D 공간정보 제공 FAQ와
학술연구 목적 공개제한 공간정보 신청 서식, 보안심사 안내를 첨부로 제공한다.
이는 3D 자료 제공 절차에 대한 것이고 배경 정사영상과는 별개이며, 첨부파일은
내려받지 않았으므로 어떤 질문에 대한 답으로도 채택하지 않는다. 첨부 목록은
`assets/yeouido_smap_ortho_provider_request.json`에 파일명과 바이트 수만
기록해 두었다.
