# V1-9 NGII 공개 기준점과 CRS 축 검증

국토정보플랫폼의 서울2447 도엽에서 공개된 공공측량 기준점 4개를 공식 메타정보
화면으로 확인했다. 이 단계의 목적은 좌표를 더 얻는 것이 아니라, 사용할 수 없는
기준점을 교량 station이나 표고 기준으로 잘못 승격하지 않는 것이다.

## 확인된 수치지도 상태

- 도엽: 서울2447 (`376082447`), 1:1,000
- 제품: 수치지형도 DXF 1건
- 표시 제작연도: 2025
- 표시 좌표체계: `GRS80`
- 도엽 이력: 이력정보 없음
- 비로그인 다운로드: 선택 후 다운로드 이벤트와 파일 모두 확인되지 않음

`GRS80`은 타원체/측지기준 표시일 뿐 투영 원점과 축을 확정하는 EPSG 코드가 아니다.
따라서 실제 배포 파일 또는 동봉 메타데이터를 확보하기 전에는 수치지도의
`projected_crs`를 계속 미확정으로 둔다.

## 공개 공공삼각점

포털의 공공측량 결과에는 CP01, CP02, CP11, NO22가 있으며 DOM 메타데이터가
좌표 참조 코드를 `5186`으로 명시한다. 성과 메타정보의 네 점은 모두 4급
공공삼각점이고 상태가 `망실`이다.

| 점 | EPSG:5186 Easting / Northing | 정표고 | 상태 |
|---|---:|---:|---|
| CP01 | 193653.691 / 547206.455 m | 12.773 m | 망실 |
| CP02 | 193647.074 / 547254.069 m | 12.674 m | 망실 |
| CP11 | 193516.006 / 547071.947 m | 12.764 m | 망실 |
| NO22 | 193342.105 / 547354.799 m | 12.012 m | 망실 |

포털의 `minx/miny`는 각각 Easting/Northing으로 해석하고 런타임 변환은
`always_xy=True`를 사용한다. 이 매핑은 네 점 모두 현재 장면 경계 안에 놓이지만,
축을 바꾸면 네 점 모두 장면 밖에 놓인다. EPSG 네이티브 축 메타데이터의
Northing(X), Easting(Y) 순서와 라이브러리의 XY 입력 규약을 혼동하지 않는다.

## 적용 판정

- 기준점 카탈로그의 CRS 참고: 허용
- 현장 기준점 사용: 차단 — 네 점 모두 망실
- 수치지도 파일 CRS 적용: 차단 — 배포 파일 미확보
- 교량 station 등록: 차단 — 서강대교 구조점 0개
- 수직 프로필 적용: 차단
- NGII 실제 파일 CLI 가져오기: 차단 — SHA-256·EPSG·라이선스 검증 전 실행 거부
- 장면 정점과 프레임 경로 변경: 없음

```powershell
python -m tools.audit_ngii_public_controls
python -m pytest tests/test_ngii_control_evidence.py tests/test_ngii_structures.py -q
```

검증 결과는 집중 테스트 18개와 전체 회귀 591개 통과다. 감사 보고서는 증거 자산과
원천 매니페스트의 SHA-256 연결, 정상 축 매핑 4/4, 축 교환 매핑 0/4, 장면 정점
수정 0개와 런타임 프레임 경로 무변경을 함께 확인한다.

다음 게이트는 인증 세션으로 2024년 또는 그 이전의 1:1,000 배포본을 확보하고,
동봉 메타데이터에서 투영 CRS와 라이선스를 확인한 뒤 서강대교의 교각·신축이음에
직접 결속되는 현존 기준점 세 개 이상을 확보하는 것이다.
