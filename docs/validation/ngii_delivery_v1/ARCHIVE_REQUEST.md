# V1-10c 서울2447 과거 배포본 요청서

이 문서는 국토지리정보원에 보낼 문의 초안과 수령 검증 체크리스트다. 저장소는
이 요청을 자동 제출하지 않으며, 신청자의 이름·연락처·소속 같은 개인정보를
기록하지 않는다.

## 문의 초안

```text
제목: 서울2447 1:1,000 수치지형도 2024년 이전 보관 배포본 제공 가능 여부 문의

2024년 10월 5일 당시 여의도·서강대교 주변 지형과 구조물을 연구용 로컬 3D
시뮬레이션에서 검증하려고 합니다. 국토정보플랫폼의 도엽번호 376082447
(서울2447), 축척 1:1,000 수치지형도 DXF/NGI는 현재 제작연도 2025 자료만
표시되고, 이력보기에는 "이력정보가 없습니다"라고 표시됩니다.

다음 조건을 만족하는 공식 보관 배포본의 존재와 신청 방법을 확인 부탁드립니다.

1. 도엽번호 376082447(서울2447), 축척 1:1,000
2. 제작연도 2024년 또는 그 이전
3. DXF 또는 NGI 원본과 원본 제작연도
4. 투영 좌표계의 명시적 EPSG 코드 또는 좌표계 정의서
5. 연구용 로컬 파생물 생성 가능 여부와 적용 이용조건
6. 제공 패키지의 파일 목록 또는 공식 인수증

2024년 이전 보관본이 없다면, 가장 가까운 제작연도와 별도 보관기관 또는
대체 공식 자료의 명칭·신청 경로도 안내 부탁드립니다. 원자료의 공개 재배포는
요청하지 않으며, 제공 조건을 준수해 로컬 검증에만 사용할 예정입니다.
```

## 제출 전 확인

- 도엽번호는 `376082447`, 도엽명은 `서울2447`로 함께 표기한다.
- 행사일은 `2024-10-05`, 허용 제작연도 상한은 `2024`로 명시한다.
- 포털의 `GRS80` 카탈로그 표기를 EPSG 코드로 단정하지 않는다.
- 신청 화면이 요구하는 이름·연락처·소속·사용 목적은 저장소에 커밋하지 않는다.
- 비용, 이용조건, 원자료 반출 제한이 표시되면 동의 전에 별도로 검토한다.

## 수령 시 보존할 증거

- 제공기관이 표시된 신청 내역, 회신 또는 인수증
- 원본 제작연도와 도엽번호가 표시된 메타데이터
- 투영 EPSG를 명시한 내장 메타데이터, 제공자 sidecar 또는 제공자 인수증
- 연구용 로컬 파생 사용과 재배포 범위를 설명하는 이용조건
- 다운로드한 원본 패키지와 압축 해제 전 파일 목록

원본 패키지는 버전 관리 밖에 보관한다. 패키지와 모든 DXF/NGI 멤버의
SHA-256·바이트 수를 `assets/yeouido_ngii_delivery_receipt.json`에 기록한 뒤
다음 검증을 실행한다.

```powershell
python -m tools.audit_ngii_delivery_readiness
python -m pytest tests/test_ngii_delivery.py tests/test_ngii_structures.py tests/test_ngii_control_evidence.py -q
```

감사가 `stage_complete=true`를 보고하기 전에는 구조물 가져오기와 장면 병합을
실행하지 않는다.
