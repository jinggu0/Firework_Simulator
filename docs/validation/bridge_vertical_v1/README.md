# V1-6 서강대교 수직 기준 증거 검증

이번 단계는 서강대교를 임의의 7m 평판에서 실제 종단 형상으로 바꾸기 위한 첫
증거 게이트다. 서울시의 공식 정밀안전진단·정밀점검 자료와 서울시의회 공개
표를 원문 렌더링해 확인하고, 세 원문 체크섬과 공개 제원을
`assets/seogang_bridge_vertical_evidence.json`에 고정했다.

## 확정된 값

- 서강대교 길이 1,320m, 항로부 경간폭 60m, 순경간 57m
- 항로부 상판 하부고 `EL 23.3m`
- 장면 EL 기준 `2.79m`를 뺀 런타임 수직 기준점 `Y=20.51m`
- 본교 폭 29~34m, 북단 접속교 길이 386m·폭 29m
- Ramp-A 길이 411.6m·폭 7.5m, 공개 대표 횡단면의 구조 깊이 2.035m

## 적용하지 않은 값

`EL 23.3m`는 항로부의 **상판 하부고**다. 어느 2024 OSM 선형 정점에 해당하는지,
그 지점의 상판 두께와 상면 EL이 얼마인지까지 등록되지 않았다. 따라서 현재
장면의 지형 상대 오프셋 7m와 직접 빼거나, 이를 상판 상면 높이로 간주하지
않았다. 공개 스캔 종단면은 육안 확인했지만 0.25m 이하 평면 RMSE와 0.10m 이하
수직 불확도를 증명하는 지오리퍼런싱이 아직 없다.
또한 세 공식 자료는 2012·2015·2019년에 작성됐으므로 2024-10-05까지 상판
교체·단면 변경이 없었는지 시설물 이력으로 확인해야 실제 행사 시점 값으로 승격된다.

`simulator.bridge_evidence`는 다음 조건이 모두 충족되지 않으면 수직 오프셋 적용을
예외로 차단한다.

1. A/B 등급 원문과 SHA-256 잠금
2. 완공도면 station과 장면 EUS 좌표 사이의 독립 기준점 세 개 이상
3. 평면 도면 해상도 0.125m/px 이하
4. 평면 등록 RMSE 0.25m 이하
5. 두 점 이상의 증가하는 종단 표본
6. 각 표본의 상판 상면 EL 또는 하부 EL+구조 깊이
7. 기록된 수직 불확도 0.10m 이하
8. 2024-10-05 행사일까지 구조 변경 이력 검증

## 재현

```powershell
python -m tools.audit_bridge_vertical_evidence
python -m pytest tests/test_bridge_evidence.py -q
```

감사 결과는 `bridge_vertical_report.json`에 저장된다. 배포 장면 SHA-256,
EL 기준, 공식 기준점 변환을 통과했고 형상 수정은 0개다. 프레임 경로를 전혀
변경하지 않으므로 예상 프레임 시간 변화는 0ms다.

다음 단계는 2024 행사일까지의 변경 이력을 확인하고, 공개 완공 종단면의
station을 2024 역사 OSM 중심선에 등록한 뒤 고해상도 도면 또는 독립
사진측량으로 상판 상면 프로필을 교차 검증하는 것이다.
