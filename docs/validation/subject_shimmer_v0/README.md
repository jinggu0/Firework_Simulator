# V0-18 교량·도로 후보 시점의 별도 깜빡임 기준선

## 측정 전 규칙

V0-17에서 가시성을 통과한 `bridge_subject_20` / `road_subject_12`만 측정한다.
기존 6시점·장면·셰이더·채택 기준은 변경하지 않는다. 결과는 새로운 카메라의
기준값이지 기존 구도 대비 개선량이 아니다.

- 각 시점에서 새 컨텍스트로 마스크 없는 회전, 정지, 마스크 포함 회전을 각각
  24프레임 촬영한다. 8프레임 준비 후 시간을 고정하고, 기존처럼 렌즈 중심에서
  회전해 화면 중앙을 프레임당 약 0.618px 이동시킨다. 반사는 매 프레임 갱신한다.
- 두 회전 촬영은 카메라 행렬·렌더 설정·GPU·채점 영역이 일치해야 한다.
  표시·선형 HDR 초과 깜빡임과 평균 표시 밝기 차이는 각 항목 기준 1% 또는
  절대 1e-6 중 큰 값 이내여야 한다. 정지와 이동의 채점 영역 교집합에서 바닥
  잡음을 비교하며, 정지 점수를 이동 점수에서 빼지 않는다.
- 전체 점수는 기존의 표시 RMS 2코드 및 상대 HDR RMS 0.05 초과 평균이다.
  지역은 이 초과 평균을 분배하지 않고, 제곱 잔차 합과 조건부 RMS로 따로 보고한다.
  현재 수신 픽셀과 재투영한 직전 프레임의 원자료 4×4 또는 16×16 지원이 모두
  같은 대상이면 내부, 모두 비대상이면 비대상, 나머지는 경계·혼합으로 분류한다.
  두 지원 폭에서 표본 합과 잔차 제곱합이 원래 전체 점수와 결속되는지 검사한다.
- 대상은 V0-17과 같은 재질·좌표 영역이다. 교량 상판·측면과 자동차 포장면을
  분류하되 교각이나 반사광의 발광원까지 식별하지 않는다. 보간 전처리의
  영향은 지원 창 밖에도 남으므로 분류는 수신 위치 진단이지 원인 귀속이 아니다.

이 검사는 회전만 다루며 보행 시차, 변화하는 파랑, 불꽃이 있는 장면과 프레임
비용은 다루지 않는다. PNG 왼쪽은 중앙 프레임쌍의 대상 내부(청록)·혼합(황색)이고,
오른쪽은 전체 경로의 표시 초과를 주황색으로 덧씌운 지도(0~8 코드에서 포화)다.

```powershell
python -m tools.measure_subject_shimmer
```

## 결과 (2026-11-11)

기준과 분류 방법을 `909b106`에 커밋한 뒤 측정했다. 1280×720, Intel Arc 140V /
`32.0.101.8626`, MSAA 8, AO 0.62, 블룸 0.72, 인간 시각 모드(고정 시선 주변부 흐림 꺼짐)다.
기존 시점의 드라이버 잔차 예외는 새 ID에 적용하지 않았다.

| 새 시점 | 전체 표시 초과 | 전체 상대 HDR 초과 | 표시 불안정 픽셀 | 정지 표시 초과 |
|---|---:|---:|---:|---:|
| `bridge_subject_20` | 0.670625 | 0.025755 | 10.30% | 0 |
| `road_subject_12` | 0.241089 | 0.009216 | 4.25% | 0.000060 |

앞 세 지표는 마스크 없는 이동 촬영이다. 정지와 이동의 공통 채점 영역에서
이동 표시 초과는 각각 0.671273과 0.241227이다. 도로의 정지 점수가 작지만 0은
아니므로 없던 것으로 처리하지 않았다. 두 시점 모두 마스크 대조 검사를 통과했다.
교량의 세 대조 지표는 동일했고, 도로의 절대 차이는 표시 초과 0.000008364,
HDR 초과 0.000001183, 표시 평균 0.000003876 코드다.

| 시점·영역 (4×4 지원) | 전체 표본 중 | 표시 제곱 잔차 중 | 표시 조건부 RMS (코드) |
|---|---:|---:|---:|
| 교량 상판·측면 내부 | 7.88% | 3.13% | 2.19 |
| 교량 경계·혼합 | 0.98% | 10.74% | 11.51 |
| 교량 비대상 | 91.14% | 86.12% | 3.39 |
| 도로 포장 내부 | 57.20% | 1.41% | 0.31 |
| 도로 경계·혼합 | 1.56% | 0.81% | 1.42 |
| 도로 비대상 | 41.24% | 97.78% | 3.04 |

지원 범위를 16×16으로 넓혀도 표시 제곱 잔차는 교량 84.89%, 도로 95.95%가 비대상이다.
교량 경계·혼합은 표본 4.05%에 잔차 14.40%로 여전히 국소적으로 집중된다.
교량 내부 조건부 RMS는 2.19에서 1.16으로 내려가므로, 지원 범위에 민감한 내부 점수를
독립적인 표면 원인으로 읽지 않는다. 도로 내부는 두 지원 범위 모두 0.30~0.31코드다.
지역별 표본 합과 제곱 잔차 합은 전체 채점 도메인 및 전체 RMS 제곱합×23과 일치했다.

[교량 지도](bridge_subject_20.png)와 [도로 지도](road_subject_12.png)에서 원경 건물과
수면 반사 부근의 큰 잔차를 확인했다. 교량 가장자리에도 좁고 강한 띠가 남는다.
두 화면의 비대상 비중은 원경 건물·수면·다른 구조물을 합친 **수신 위치 비중**이다.
반사광의 원천이나 어떤 셰이더 단계가 잔차를 만들었는지는 아직 분리하지 않았다.

기존 6시점, 장면, 셰이더와 품질 설정은 그대로다. 시각 진척률과 성능은 재평가하지 않았다.
