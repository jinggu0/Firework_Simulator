# V1 지형·수변 접촉 오차 지도

이 산출물은 현재 `assets/yeouido_scene.npz`의 렌더 표현에서 지형, 수변과 도로가
시각적으로 분리될 가능성이 큰 위치를 찾는다. 실제 표고와의 차이를 측정한 측량
성과가 아니며, 보정 작업의 우선순위를 정하는 공학적 결함 지도다.

재생성 명령:

```powershell
python -m tools.audit_terrain_contacts `
  --output-dir docs/validation/terrain_contact_v1
```

## 2026-08-03 기준 결과

- 지형 격자 간격: 동서 4.888m, 남북 3.910m
- 수변을 제외한 38도 이상 급경사 표본: 2,313개
- 물 기준면과 4m 이상 차이 나는 인접 육지 수변 표본: 311/3,617개
- 도로 목표 여유 높이 6cm에서 5cm 이상 아래로 벗어난 표본: 20,215개
- 도로 목표 여유 높이 6cm에서 5cm 이상 위로 벗어난 표본: 21,662개
- 육지 도로 편차 절댓값이 20cm 이상인 우선 보정 표본: 13,511개
- 교량으로 분류되지 않은 도로의 수면 표본: 427개
- 100m 구간 우선순위: P0 271개, P1 261개, P2 360개

도로 수치는 각 삼각형의 중심과 세 변 중점을 검사한 표본 수다. 공유 변에서는
같은 지리 위치가 중복될 수 있으므로 도로 개수나 고유 결함 개수로 해석하지 않는다.

## 지도 범례

- 주황: 수변을 제외한 38도 이상 급경사 지형
- 자홍: 물 높이 0m와 직접 맞닿지만 육지 높이가 4m 이상인 수변
- 빨강: 렌더된 도로가 목표 지형 접촉보다 5cm 이상 낮은 표본
- 청록: 렌더된 도로가 목표 지형 접촉보다 5cm 이상 높은 표본
- 보라: 교량 배치가 아닌 도로가 수면 마스크 위를 지나는 표본

P0는 도로 편차 0.5m 이상, 수변 단차 8m 이상, 지형 경사 60도 이상 또는
미분류 수면 횡단 중 하나가 있는 100m 구간이다. P1은 도로 편차 0.2m 이상,
수변 단차 4m 이상 또는 지형 경사 50도 이상인 구간이다. 이 분류는 화면 결함
수정 순서이며 실제 위험도나 법적 시설 등급이 아니다.

## 다음 보정 순서

1. P0 도로 구간에서 삼각형 내부 지형 추종 오차와 실제 급경사 자료 오류를 분리한다.
2. 행사장과 직접 보이는 북측 수변의 4m 이상 접촉부를 옹벽·사면·호안 증거와 대조한다.
3. 미분류 수면 횡단 427개 표본을 교량, 마스크 오차, 잘못 연결된 도로로 분류한다.
4. 보정 전후에 같은 명령을 실행해 P0/P1 구간과 최대 편차가 감소했는지 확인한다.

원시 수치와 모든 100m 구간은 `terrain_contact_audit.json`, 시각 지도는
`terrain_contact_audit.png`에 저장되어 있다.
