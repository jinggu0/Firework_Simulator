# V0-19 교량·도로 기준선의 비대상 잔차 분리

## 측정 전 규칙

V0-18의 두 24프레임 회전 경로와 채점법을 그대로 사용한다. 카메라·장면·기존 6시점·
출하 셰이더는 바꾸지 않는다. 새 보조 마스크는 기존 대상 채널을 유지하고, **250m 이상
떨어진 벽면 재질**과 **깊이 테스트를 통과한 직접 수면**을 추가한다. 250m는 원경을
분리하기 위한 고정 공학적 기준이다. 더 가까운 벽면, 지붕, 하늘, 지형 등은 기타다.
수면은 빛을 받는 위치이지 반사광의 발광원이 아니다.

현재 수신 픽셀과 재투영한 직전 원자료 4×4 / 16×16을 검사한다.
기존의 **대상 내부·대상 경계/혼합이 항상 먼저**다. 기존 비대상만 아래로 세분한다.

- 원경 파사드 또는 수면 내부: 현재와 직전 지원 전체가 해당 분류.
- 원경 파사드 혼합 또는 수면 혼합: 해당 분류가 일부 포함되고 상대 분류는 없는 지원.
- 파사드·수면 공동 혼합: 현재 또는 직전 지원에서 두 분류가 모두 나타남.
- 기타: 현재와 직전 지원에 파사드·수면 분류가 모두 없음.

새 마스크 경로는 V0-18 보고서와 카메라·환경·채점 수를 대조한다. 표시·HDR 초과와
평균 표시 밝기는 기존 마스크 없는 대조와 각각 1% 또는 절대 1e-6 중 큰 범위
이내여야 한다. 새 분류를 세 개의 원래 분류로 되합쳤을 때 표본 수는 정확히 같고,
표시·HDR 제곱 잔차 합은 원래 분류와 각각 같은 허용 범위 이내여야 한다.
새 집계 자체는 기존과 같은 RMS 제곱합×23 및 전체 표본 수를 보존해야 한다.

보간 전처리 및 블룸·AO의 영향은 지원 범위를 넘을 수 있다. 분류는 수신 위치의
진단이며 원인, 수정 효과, 실사 유사도 또는 프레임 비용의 측정이 아니다.

```powershell
python -m tools.measure_background_shimmer
```
