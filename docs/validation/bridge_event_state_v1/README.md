# V1-8 서강대교 행사일 상태와 종단면 등록 증거 감사

이 단계는 2024-10-05 서강대교의 비계·도장 상태와 실제 종단면을 근거 없이
렌더링하지 않도록 행사 사진, 공사 기록, 공식 도면의 적용 한계를 코드로 고정한다.

## 행사일 외관 판정

날짜와 원본 이미지가 확인되는 행사 보도 사진 4개를 검토했다. 독립 시점은 3개지만
모두 주 발사 수역과 IFC·Parc.1 방향을 담고 있어 서강대교가 식별되지 않는다.
따라서 하부 공중비계와 새 도장 경계는 모두 `unresolved`이며 렌더링하지 않는다.

서울시 계약은 행사일에 진행 중이었고 공중비계 14,556㎡를 포함한다. 반면 행사일
서울경찰청 도로공사 목록에는 이 공사가 없다. 이는 교통 통제를 동반한 상판 작업이
목록에 없었다는 뜻으로만 사용하며, 하부 비계가 없었다는 결론으로 확대하지 않는다.

## 종단면 등록 판정

체크섬이 기존 증거와 일치하는 2015 공식 HWP의 임베디드 도면을 직접 추출했다.

- `BIN0012.jpg`: 4,964×3,510px, P8-P9 닐센 아치와 교각간 150.000m 확인
- `BIN0013.jpg`: 4,964×3,510px, P8/P9 아치 리브 상세; 제작 주석을 도로 station으로 사용하지 않음
- `BIN00C1.bmp`, `BIN00C3.bmp`: 약 1,200px 폭의 본교 종단 래스터 두 장

독립적으로 식별되는 기준점은 P8과 P9 두 개뿐이다. 종단 래스터의 보수적인 평면
해상도 하한은 0.5m/px로 새 기준 0.125m/px보다 네 배 거칠고, 정합 대상인 역사
OSM은 C등급이다. 따라서 세 기준점·A/B등급 평면·0.25m RMSE 조건을 통과하지 못한다.

2019 공식 보고서 4~5쪽은 준공도면과 보수·보강 이력 보유, 주요 설계변경 내역
없음을 확인하지만 이는 2019년까지의 기록이다. 행사일까지의 구조 변경 부재는
아직 증명되지 않았다.
