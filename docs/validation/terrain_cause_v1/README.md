# V1-3 행사장 지형 접촉 원인 분리

이 분석은 행사장 북측 수변 우선 범위에서 도로 접촉 결함이 원본 높이장 때문인지,
낮은 도로 메시 밀도 때문인지 분리한다. 원본 1024² 지형은 변경하지 않고 모든 도로
삼각형을 변 중점에서 반복 분할한 뒤, 새 정점이 같은 높이장을 다시 표본화한다고
가정한 반사실험이다.

재생성 명령:

```powershell
python -m tools.analyze_terrain_causes `
  --output-dir docs/validation/terrain_cause_v1
```

## 우선 범위

`event_park_north_bank`는 로컬 EUS 좌표 `[-1200, -550, 600, 950]m`다. 서울시
공식 시설 자료의 이벤트광장·너른들판·잔디마당·매점·선착장 9개 지점과 정적 회귀
카메라 6개를 포함하도록 정한 C등급 공학 범위다. 2024 행사 통제선, 관람객 경계나
실제 촬영 범위를 뜻하지 않는다.

## 결과

| 도로 표현 | 삼각형 배수 | 5cm 이상 편차율 | 20cm 이상 편차율 | 50cm 이상 편차율 |
|---|---:|---:|---:|---:|
| 현재 L0 | 1× | 5.1688% | 0.8800% | 0.2839% |
| 1회 분할 L1 | 4× | 1.2368% | 0.2620% | 0.0360% |
| 2회 분할 L2 | 16× | 0.2955% | 0.0349% | 0.0048% |

- L2에서 20cm 이상 편차 비율은 현재보다 96.03% 감소한다.
- 현재 AOI의 20cm 이상 표본 403개는 모두 38도 미만 높이장 위에 있다.
- L2 뒤에도 국소 최대 편차 1.172m와 우선 표본 256개가 남는다. 표본 총수가
  16배로 증가하므로 개수 대신 비율로 전후를 비교해야 한다.
- 북쪽에 물이 바로 인접한 행사장 수변은 348표본이며 높이는 중앙값 2.210m,
  p95 2.360m, 최대 2.654m다. 이 범위에는 4m 이상 수변 단차가 없다.

따라서 행사장 도로 접촉의 주원인은 공식 높이장을 따라가는 정점의 간격이 부족한
것이다. 그러나 전체 도로를 무조건 L2로 바꾸면 정점 수가 이론상 16배가 되므로
노트북 60 FPS 목표에 부적합하다. 다음 구현은 화면에 보이는 AOI와 오차가 큰
삼각형만 최대 L2까지 세분하는 적응형 방식이어야 한다. 잔류 0.0349%는 높이장
급곡률, 수변 마스크 근접, 도로 연결 형상을 별도로 판정한다.

원시 수치는 `terrain_cause_report.json`, AOI·북측 수변·현재/잔류 도로 표본은
`terrain_cause_map.png`에 저장되어 있다.
