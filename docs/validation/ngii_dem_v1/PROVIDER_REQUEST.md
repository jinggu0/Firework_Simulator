# V1-11d NGII DEM 공식 제공 요청서

이 문서는 포털의 공개 DEM 신청 API가 정상 배포를 시작하지 못한 상태에서
공식 제공 경로로 전달할 문의 초안과 수령 검증 체크리스트다. 프로젝트 소유자는
제출 진행을 승인했지만 공공데이터포털의 별도 사용자 인증이 완료되지 않아 아직
외부 제출되지 않았다. 저장소는 신청자의 이름·연락처·생년월일 같은 개인정보를
기록하지 않는다.

공공데이터포털의 `공공데이터 제공신청` 경로에서 아래 내용을 검토해 붙여 넣을 수
있다. Chrome에는 정부 통합인증 또는 공공데이터포털 아이디 로그인 선택 화면을
인계했으며, 사용자가 인증을 완료한 뒤 같은 탭에서 제출을 계속한다.

## 문의 초안

```text
제목: 여의도 2024 공개 DEM 직접 제공 및 수치표고 정확도 문서 요청

2024년 10월 5일 당시 여의도와 인접 한강 구간의 지형·구조물 표고를 연구용
로컬 3D 시뮬레이션에서 검증하려고 합니다. 대상 범위는 WGS84 기준
126.910–126.960°E, 37.515–37.545°N입니다.

국토정보플랫폼에서 공개DEM `2024 서울 37608`을 선택해 신청했으나, 포털
프런트엔드가 JSON `orderDownList`를 기대하는 DEM 신청 주소에서 HTTP 200
text/html의 `요청하신 페이지를 찾을 수 없습니다` 화면이 반환됩니다. 마이페이지
공개DEM 신청 건수도 증가하지 않고 원본 파일도 전달되지 않았습니다.

다음 순서로 공식 자료와 메타데이터를 제공하거나 정상 신청 경로를 안내해 주시기
바랍니다.

1. 우선 요청: 공개DEM `2024 서울 37608` 원본 패키지 또는 정상 다운로드 경로
2. 위 자료를 제공할 수 없는 경우: 2009년 항공 LiDAR 1m ASCII DEM
   `37608087(서울087)`, `37608088(서울088)`, `37608089(서울089)`,
   `37608097(서울097)`, `37608098(서울098)`, `37608099(서울099)` 원본
3. 배포물에 명시된 투영 좌표계/EPSG, 수직 기준면과 높이 종류, 격자 간격,
   NoData 값, 제작일과 원시자료 취득일
4. RMSE·LE90 또는 이에 준하는 수평·수직 정확도/품질 문서
5. 제공 패키지의 공식 파일 목록·체크섬 또는 인수증
6. 연구용 로컬 파생물 생성과 결과물 공개·재배포에 적용되는 이용조건

공개 메타데이터에는 2009년 여섯 도엽의 표고 기준이 인천항 평균해수면,
높이 종류가 정표고라고 표시되지만 정확도 값이 비어 있어 원본 래스터와 품질
문서 없이는 사용 적합성을 판단할 수 없습니다. 원자료의 임의 재배포는 요청하지
않으며 제공 조건을 준수하겠습니다.
```

## 제출 전 확인

- 우선 제품 `2024 서울 37608`과 대체 도엽 여섯 개가 모두 적혀 있는지 확인한다.
- 신청 화면이 요구하는 개인정보는 외부 공식 화면에만 입력하고 저장소에 옮기지
  않는다.
- 포털 오류 화면, 신청 시각, 신청 번호가 있다면 신청자 로컬 기록으로 보존한다.
- 비용·이용조건·원자료 반출 제한은 동의 전에 별도로 검토한다.

## 수령 시 보존할 증거

- 제공기관, 신청 번호와 회신 또는 공식 인수증
- 원본 패키지 파일명·바이트 수·SHA-256과 압축 해제 전 파일 목록
- 래스터 헤더 또는 제공자 sidecar에 적힌 투영 EPSG·수직 기준면·격자·NoData
- 제작/취득 시점과 RMSE·LE90 또는 동등한 정확도 문서
- 연구용 로컬 파생 사용과 결과 재배포 범위를 설명하는 이용조건

원본은 버전 관리 밖에 보관한다. 수령 증거를 결속한 뒤에도 평면 등록 RMSE
0.25m 이하와 수직 불확도 0.10m 이하가 확인되기 전에는 기존 지형을 교체하거나
구조물 메시를 병합하지 않는다.
