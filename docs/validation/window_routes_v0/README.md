# V0-20 원경 창 발광의 직접·반사 경로 분리

## 측정 전 규칙

V0-19의 카메라 두 개, 24프레임 회전 경로, 장면과 출하 렌더 설정을 그대로 쓴다.
파일의 생산 셰이더 대신 메모리에만 진단 셰이더를 로드한다. 마지막 파사드
출력에서 **실제 눈 위치 기준 250m 이상인 벽면의 창 발광 항만** 0으로 바꿀 수 있다.
근경 발광, 교량 LED, 반사 재질, 수면 파랑·반사 셰이더, 기하와 가림은 유지한다.
거리 판정에 반사 카메라의 뒤집힌 Y 좌표를 쓰지 않는다.

각 시점에서 새 컨텍스트 3개로 같은 셰이더를 실행한다.

- 대조: 두 경로 모두 그대로.
- 직접 끔: 일반 장면 그리기에서만 원경 창 발광 제거.
- 반사 끔: 평면 반사 장면 그리기에서만 원경 창 발광 제거.

조건별 실제 draw 호출과 억제 횟수를 기록한다. 첫 이동 포즈의 평면 반사 RGB
버퍼도 대조와 비교한다. 반사 끔의 평균 절대 차이는 1e-8보다 커야 하며, 직접
끔의 차이는 1e-8과 반사 끔 차이의 1% 중 큰 값 이내여야 한다. 이 검사는 반사
버퍼 단계만 확인한다. 블룸·노출 등은 직접 발광 변화의 영향을 다른 픽셀에 옮길 수 있다.

대조의 표시/HDR 초과·평균 표시 밝기 및 지역별 표본/에너지는 V0-19와 대조한다.
표본 수는 같아야 하고, 나머지 차이는 원래 값의 1% 또는 절대 1e-6 중 큰 값 이내다.
지역은 V0-19의 **4×4 지원**을 사용하며, 첫 대조 경로에서 만든 프레임쌍별 수신 위치
분류와 픽셀별 HDR 정규화 분모를 나머지 두 조건에도 고정한다. 전체 점수는 기존
방식을 유지하고, 지역별 표시 제곱 잔차·상대 HDR 제곱 잔차·표시/선형 평균 밝기는
별도 보고한다. 교량 경계는 이전과 같은 분류다.

발광을 끄면 밝기도 낮아질 수 있다. 이 실험은 생산 후보의 채택 판정이 아니며,
잔차 감소율을 순수한 원인 비율이나 더할 수 있는 개선량으로 읽지 않는다.
회전 경로만 검사하고 성능·보행·실사 유사도는 평가하지 않는다.

```powershell
python -m tools.measure_window_routes
```

## 2026-11-11 측정 결과

`e9e5e51`의 규칙으로 Intel Arc 140V, MSAA 8×에서 총 6회 촬영했다.
두 시점 모두 V0-19 대조를 통과했고, 각 촬영의 직접 32회·반사 25회 draw 중
지정한 경로에서만 억제가 실행됐다. 첫 이동 포즈의 반사 RGB 버퍼는 직접 끔에서
두 시점 모두 대조와 동일했다. 반사 끔에서는 교량 2,392픽셀(전체 버퍼 RGB
평균 절대 차이 4.29e-5), 도로 2,728픽셀(3.94e-5)이 달라졌다.

지역 잔차는 대조 대비 **표시 제곱 잔차 합**의 변화율이다. 원경 외벽과 수면은
각각 내부+혼합을 합산하며, 밝기는 같은 표본의 평균 표시 코드다.

| 시점 | 조건 | 전체 표시 초과 | 원경 외벽 잔차 | 외벽 밝기 | 수면 잔차 | 수면 밝기 |
| --- | --- | ---: | ---: | ---: | ---: | ---: |
| 교량 | 대조 | 0.670625 | — | 48.77 | — | 31.11 |
| 교량 | 직접 끔 | 0.432140 | −82.01% | 29.08 | <0.01% 변화 | 31.11 |
| 교량 | 반사 끔 | 0.565829 | <0.01% 변화 | 48.77 | −33.98% | 30.29 |
| 도로 | 대조 | 0.241112 | — | 52.36 | — | 44.17 |
| 도로 | 직접 끔 | 0.136411 | −79.06% | 33.72 | +0.01% | 44.17 |
| 도로 | 반사 끔 | 0.201875 | <0.01% 변화 | 52.36 | −29.33% | 38.71 |

교량 시점의 주제 경계는 직접 끔에서 표시 제곱 잔차 변화가 0.01% 미만이었고,
반사 끔에서는 **+0.38%**였다. 따라서 외벽이나 수면의 감소를 교량 경계의 개선으로
간주하지 않는다. 직접 끔의 전체 표시 초과는 두 시점에서 반사 끔보다 더 크게
감소했지만 외벽의 밝기도 크게 떨어졌다. 이 수치는 우선순위를 정하기 위한 것이며
원인 비중이나 출하 가능한 개선량은 아니다.

다음은 **직접 경로의 원경 창 발광을 평균 밝기와 세부를 보존하면서 안정화**하는
후보다. 두 시점의 지역 잔차와 밝기를 함께 재측정하고, 채택 전 기존 여섯 시점의
비악화와 4px/16px 세부 보존을 확인한다. 반사와 교량 경계는 별도 지표로 유지한다.
