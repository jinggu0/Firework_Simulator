# 회귀 카메라 배치 검증

## 결함: `facade_landmark` 카메라가 건물 안에 있었다

`facade_landmark`는 2026-08-03(`2ed48cb`)에 정의된 날부터 **높이 49m 건물의 내부**에
서 있었다. 장면 자산은 그보다 앞선 `5d6c8ef` 이후 바뀌지 않았으므로, 이 시점은 처음부터
실재하지 않는 방의 안쪽 벽을 렌더해 왔다.

| 항목 | 값 |
|---|---|
| 카메라 | (-650.0, 28.8274, 900.0) EUS m, 지형 위 18.0m |
| 머리 위 건물 면 | 31.17m 위(지붕 y=60m) |
| 가장 가까운 건물 면 | 0.18m |
| 렌더 커버리지 | 100%, 하늘 없음 |
| 기하 거리 | 21.9 ~ 39.7m (선언된 조준점은 1,143.5m) |

기존 게이트가 이를 통과시킨 이유: 캡처 게이트는 **지형까지의 여유 높이만** 쟀다.
닫힌 건물 셸 안이라도 지면에서 18m 위이면 통과한다.

## 게이트

`simulator/validation/view_placement.py`가 건물 메시로 두 가지를 검사하고,
`tools/capture_visual_baselines.py`는 첫 렌더 전에 선택된 모든 시점에 적용한다.

- **머리 위 건물 면**: 장면의 건물은 벽과 지붕만 있고 바닥이 없는 압출 풋프린트이므로,
  카메라 바로 위에 건물 면이 있으면 곧 건물 내부다
- **렌즈 여유**: 가장 가까운 건물 면까지의 거리가 `CameraConfig.camera_collision_radius_m`
  (0.12m) 이상이어야 한다. 대화형 카메라가 이미 지형과 유지하는 반경이라 새 허용치를
  만들지 않았다. 거리는 면의 평면이 아니라 삼각형의 **실제 최근접점**까지 잰다

## 이전 규칙

미관으로 고르지 않았고, 이전된 시점을 렌더해 보기 전에 규칙을 정했다. 다만 렌즈 여유
조건은 첫 탐색에서 건물을 벗어난 35m 지점이 벽에서 약 0.1m뿐임을 본 뒤, 새 값을 만들지
않고 기존 `camera_collision_radius_m`로 추가했다.

> 선언된 조준점을 향한 수평 방위를 따라 1m 단위로 전진하되 조준점과 지형 위 여유
> 높이를 유지하고, 머리 위 건물 면이 없고 모든 건물 면이 렌즈 여유 이상 떨어지는
> 첫 지점에서 멈춘다.

- 34m: 여전히 머리 위에 건물 면(31.36m)
- 35m: 건물은 벗어났지만 벽까지 0.089m — 렌즈 여유 미달
- **36m: 통과** → (-635.8189, 28.632, 866.9108), 가장 가까운 면 0.96m

방위각은 23.1986°로 그대로, 앙각은 2.5649°→2.6583°, 조준점까지 1,143.5m→1,107.6m.
이전 후 커버리지 97.2%, 기하 거리 40.9 ~ 693.3m이며 원래 건물은 화면 광선 627개 중
0개에 걸린다.

규칙은 `advance_out_of_buildings`로 구현했고, `test_the_shipped_facade_camera_is_the_rule_applied_to_the_enclosed_one`이
**옛 좌표에 규칙을 적용하면 출하된 좌표가 정확히 나오는지** 검사한다. 시점 파일의
설명이 주장하는 내용을 테스트가 검증하는 구조다.

## 이 검증이 하지 않는 것

- 각 시점이 선언된 주제를 **잘 보여주는지**는 판정하지 않는다. `bridge_structure`의
  중앙 시선은 1,443.5m 조준점 대신 270.6m에서 Parc.1 타워에 막히고, `road_ground`는
  렌더 픽셀의 절반이 1.1m 안쪽의 어두운 면이다. 둘 다 건물 내부는 아니며, 판정하려면
  아직 없는 주제 가시성 기준이 필요하다
- 건물 메시 밖의 기하(교량, 옥상 설비, 계단)는 내부 판정에 쓰지 않는다

## 영향

- 시점 파일 해시가 `bc3c1272…` → `54aa2c58…`로 바뀐다. 이전에 찍은 로컬 캡처와
  비교하면 `views_asset_sha256` 불일치로 **정상적으로 거부**되며, 기준 캡처는 다시
  떠야 한다
- 나머지 다섯 시점의 가장 가까운 건물 면은 2.18m(`grass_close`) ~ 109.6m이고 좌표는
  바뀌지 않았다
- V2-3a/3b에서 `facade_landmark`로 잰 모든 수치는 건물 내부를 잰 것이다.
  정정은 `docs/validation/aliasing_v2/README.md`에 있다
