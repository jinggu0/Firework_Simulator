# 여의도 시각 품질 로드맵

최종 갱신: 2026-08-03  
현재 단계: **V1-11c 포털 API 결함 확인 → 1m DEM 대체 인수 경로 결정**
로드맵 상태: **진행 중**

## 1. 목표와 작업 순서

이 로드맵의 일차 목표는 불꽃 공연이 없어도 2024년 10월의 여의도 한강공원이
실사처럼 보이는 3D 공간을 만드는 것이다. 실제 2024-10-05 공연의 발사 위치,
큐시트, 팀별 연출과 시간축은 정적 환경과 일반 불꽃·연기 표현이 목표 품질을
통과한 뒤 결합한다.

고정 우선순위는 다음과 같다.

1. 여의도 지형, 제방, 수변 경계와 표고
2. 잔디, 흙, 포장, 도로와 지표의 미세 형상
3. 건물 외벽, 창호, 옥상과 주요 랜드마크
4. 교량, 수목, 난간, 가로등과 공원 시설물
5. 야간 조명, 그림자, 대기 원근과 화면 안정성
6. 한강 수면, 파랑, 수심 색과 반사
7. 실제 공연과 독립된 단일 불꽃의 형태와 광학 표현
8. 연기 유체, 광산란과 장면 상호 조명
9. 전체 시각 경로의 노트북 60 FPS 안정화
10. 2024-10-05 실제 공연의 위치·시간·연출 결합

앞 단계의 완료 조건을 충족하지 못한 상태에서 뒤 단계의 외관 튜닝으로 문제를
가리지 않는다. 단, 뒤 단계 구현에 필요한 계측·자료 수집·인터페이스 설계는
병렬로 준비할 수 있다.

## 2. 최종 품질 계약

### 시각 품질

- 자유 카메라의 지상 보행 높이와 대표 원경 시점 모두에서 지형이 평면처럼
  보이지 않아야 한다.
- 잔디, 도로, 흙, 콘크리트와 건물 외벽은 색상 패턴만 바뀌는 평면이 아니라
  실제 크기의 거칠기, 법선, 경계 높이와 실루엣을 가져야 한다.
- 63빌딩, IFC, Parc.1, FKI, 국회의사당과 주요 교량은 일반 빌딩 대체물이
  아니라 공개 증거로 확인 가능한 매스, 외장 구성과 야간 특징을 가져야 한다.
- 불꽃은 서브픽셀 단계에서도 방사 궤적이 분리되고 시간에 따라 추진·항력·중력
  영향을 보여야 한다. 밝기 증가는 궤적을 두꺼운 흰 원으로 합치면 안 된다.
- 연기는 밀도·온도·속도장과 광학 두께를 연결하고, 불꽃 빛을 받아 공간적인
  색과 그림자를 형성해야 한다.
- 실제 공연 결합 전까지 모든 데모 불꽃은 명확히 `synthetic`으로 식별한다.

### 성능과 물리 보존

- 기준 해상도는 1280×720, 표시 목표는 60 FPS, 물리 고정 주기는 120 Hz다.
- 노트북 기준 세 번의 독립된 360프레임 통합 측정 모두에서 프레임 p95가
  16.67 ms 미만이어야 해당 시각 단계가 완료된다. p99와 시각·물리 구간 p95도
  함께 기록한다.
- 성능을 위해 지형·건물의 실제 위치, 물리 고정 주기, 유체 보존식이나 압력
  반복을 임의로 낮추지 않는다. 가변 품질은 반사 해상도, 체적 광선 수와 같이
  화면 공간 오차를 측정할 수 있는 항목에만 적용한다.
- 질량, 열에너지, 광원 에너지와 결정성 회귀 검사를 유지한다.

### 증거와 검증

- A/B 등급 측량·사진측량 자료는 실측·재구성 형상에 사용할 수 있다.
- C/D 등급 추정치는 시각적 공백을 메울 수 있지만 파일과 런타임 메타데이터에
  추정임을 남기며, 실제 위치·재질로 표현하지 않는다.
- 등록 가능한 기준 사진은 카메라 재투영 오차를 먼저 통과해야 실루엣·재질
  비교에 사용한다. 포즈가 없는 사진은 색, 명암, 물결과 연기 형태 참고에만
  사용한다.
- 각 단계는 대표 시점의 동일 조건 캡처, 정량 지표, 육안 비교표를 남긴다.

픽셀 등록된 기준 자료가 부족하므로 외관 유사도 측정값으로 해석하지 않는다.

|---|---|---:|---:|---|
| V0 | 기준 화면·검증 체계 | 진행 중 | 70% | 대표 카메라, HDR/SDR 캡처, 사진 등록, 품질 점수표 |
| V1 | 지형·제방·수변 형상 | 진행 중 | 87% | 표고·경사·수변 실루엣과 지상 카메라 오차 검증 |
| V2 | 잔디·흙·도로·포장 | 진행 중 | 30% | 실측 스케일 재질, 경계 형상, 근·중·원거리 LOD |

| V4 | 교량·수목·시설물 | 진행 중 | 33% | 주요 구조와 증거 기반 배치, 반복 패턴 제거 |
| V5 | 조명·그림자·화면 안정성 | 진행 중 | 35% | TAA, 동적 그림자, 야간 명암과 노출 기준 통과 |
| V6 | 한강 수면·반사 | 진행 중 | 40% | 실제 풍속 기반 파랑, 반사 폭·파단·수변 접촉 검증 |

시각 우선 범위 V0~V9의 현재 종합 진행률은 약 **42%**다. 구조와 물리 기반은
그보다 앞서 있지만, 최종 화면을 결정하는 측량 자료, 외장 정합, 화면 안정화와
연기 조명이 아직 부족하다.

## 6. 매 턴 진행 업데이트 규칙

앞으로 구현 턴마다 이 문서의 `최종 갱신`, `현재 단계`, 진행 현황과 체크박스를
실제 상태에 맞게 수정한다. 사용자에게 보내는 완료 보고는 반드시 다음 형식을
포함한다.

```text
현재 단계: V?-?
이번 턴 완료: 구현·자료·검증 내용
품질 변화: 전후 화면 또는 정량 지표
성능: frame/visual/physics p95와 측정 조건
검증: 테스트 수와 실패·미구현 지표
남은 위험: 자료 부족 또는 기술 병목
다음 작업: 바로 이어서 수행할 한 단위
커밋: 해시와 메시지
```

상태 정의는 다음과 같다.

- `대기`: 우선순위상 아직 시작하지 않음
- `진행 중`: 일부 산출물이 존재하지만 완료 게이트를 통과하지 못함
- `차단`: 필요한 외부 자료나 권한 없이는 정직하게 진행할 수 없음
- `완료`: 자료·시각·성능·회귀 게이트를 모두 통과함

## 7. 커밋 규칙

- 하나의 검증 가능한 작업 단위를 하나의 커밋으로 남긴다.
- 구현과 그 구현의 테스트·문서·측정값은 같은 커밋에 포함할 수 있다.
- 여러 시각 영역을 한 커밋에서 임의로 섞지 않는다.
- 점검만 수행하고 파일을 바꾸지 않은 턴에는 빈 커밋을 만들지 않는다.
- 커밋 메시지는 한국어 Conventional Commit을 사용한다.

예시:

```text
feat: 지형 기준 카메라와 시각 회귀 캡처 구현
feat: 제방 단면과 호안 접촉 형상 정밀화
feat: 잔디 근거리 미세 형상과 시간 안정화 구현
perf: 수목·잔디 GPU 컬링 최적화
fix: 연속 연소 연기의 보존적 격자 주입 수정
docs: 시각 품질 로드맵 진행 상태 갱신
```
